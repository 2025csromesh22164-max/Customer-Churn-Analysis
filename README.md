# Customer Churn Analysis

## Task 2 – Data Quality and Exploratory Analysis

This project analyzes a customer churn dataset and documents data-quality checks and exploratory analysis.

## Objectives

- Check missing values
- Check duplicate records
- Validate data types
- Analyze summary statistics
- Calculate customer churn rate
- Explore churn by contract type
- Explore churn by subscription type
- Analyze support tickets
- Identify important customer churn patterns

## Key Findings

- Total customers: 15
- Churned customers: 7
- Non-churned customers: 8
- Churn rate: 46.67%
- Retention rate: 53.33%
- Month-to-month contracts showed the highest churn in this sample.
- Churned customers had shorter average tenure.
- Churned customers had more support tickets on average.
